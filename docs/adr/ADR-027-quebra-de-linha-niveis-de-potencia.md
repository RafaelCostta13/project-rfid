# ADR-027 — Exibição dos níveis de potência das antenas

## Contexto

Uma lista extensa de níveis de potência pode ficar cortada na tela de antenas.

## Decisão

Exibir os níveis com quebra automática conforme a largura disponível e rolagem vertical quando necessário.

## Consequências

Os valores continuam acessíveis sem aumentar indefinidamente a altura da tela ou ocultar os controles das antenas.
