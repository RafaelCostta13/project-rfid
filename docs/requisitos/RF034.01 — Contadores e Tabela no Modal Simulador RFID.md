Projeto: DSV RFID System

Tecnologia: Python + PySide6/QML

Prioridade: Média

---

## 1. OBJETIVO

Melhorar a interface do modal Simulador RFID,
implementado no RF034.

Atualmente, o modal apresenta:

- Título Simulador RFID.
- Estado da sessão.
- Botão Iniciar sessão.
- Botão EPC encontrado.
- Botão Extra box.
- Botão Finalizar sessão.

Adicionar:

1. Contador de EPCs encontrados.
2. Contador de Extra box.
3. Tabela de registros simulados com 7 colunas.

IMPORTANTE:

Não recriar o simulador.

Não modificar a lógica dos botões existentes.

O objetivo é apenas melhorar a apresentação
dos dados e integrar os componentes visuais
ao funcionamento atual.

## 4. CONTADOR EPCs ENCONTRADOS

Adicionar um card:

    EPCs encontrados

Cor principal:

    Verde

Valor inicial:

    0

Ao clicar em EPC encontrado:

    contador += 1

Exemplo:

    Primeiro clique: 1
    Segundo clique: 2
    Terceiro clique: 3

O contador deverá refletir exatamente
a quantidade de EPCs encontrados
na sessão simulada.

Não consultar o backend.

Não depender do leitor Zebra.

Não duplicar contadores na camada Python.

Utilizar o estado já existente no RF034.

## 6. TABELA DE REGISTROS

Adicionar uma tabela dentro do modal.

A tabela deverá apresentar os registros
gerados durante a sessão simulada.

Utilizar exatamente as 7 colunas
definidas no RF030:

1. Status
2. Cliente
3. Nota Fiscal
4. Volume
5. Pedido
6. Doca
7. Dealer

Não adicionar colunas extras.

Não substituir os nomes existentes.

Mapeamento:

    Status      -> classificação simulada
    Cliente     -> fornecedor
    Nota Fiscal -> notafiscal
    Volume      -> volume
    Pedido      -> pedido
    Doca        -> doca
    Dealer      -> destinatario

O EPC deverá permanecer disponível
internamente no modelo do registro,
mesmo não aparecendo como coluna.

    Volume: 1/1

    Doca: DOCA 42
    Dealer: DEALER TESTE

Utilizar os dados fictícios já
implementados no RF034.

Não gerar dados novos apenas
para preencher esta tabela.

### Extra box

Adicionar uma linha com o estilo
Extra box existente.

Preservar:

    Fundo: #3A372C
    Hover: #454031
    Destaque: #D9B86C

Exibir a classificação:

    Extra box

Não reproduzir bip.

## 14. PRESERVAR A TELA START

O RF034 já atualiza a tela Start
com os registros simulados.

Preservar esse comportamento.

Os contadores e a tabela do modal
deverão refletir os mesmos dados
da sessão simulada.

Não criar duas listas independentes
que possam ficar inconsistentes.

A fonte de dados deverá ser única.

Exemplo:

    Sessão simulada
          |
          v
    Modelo de registros
          |
          +--> Tela Start
          |
          +--> Modal Simulador RFID

Se o operador gerar um EPC encontrado:

- Contador Start atualizado.
- Contador modal atualizado.
- Tabela Start atualizada.
- Tabela modal atualizada.
- Bip RF033 solicitado.

Não duplicar o registro.
